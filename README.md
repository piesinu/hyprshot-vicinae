# Hyprshot – Vicinae Extension

A minimal Vicinae extension for controlling **Hyprshot** on Hyprland.  
Provides quick access to screenshot actions and basic configuration.

## Features

- Take screenshots in three modes:
  - Workspace
  - Window
  - Selection
- Toggle clipboard-only mode
- Set screenshot delay
- Set screenshot directory

## Requirements
- Hyprshot
- Vicinae
